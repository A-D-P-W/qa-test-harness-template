# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's private vulnerability reporting:
https://github.com/A-D-P-W/qa-test-harness-template/security/advisories/new

Do not open a public issue for a vulnerability. Include the affected file or commit, the steps to reproduce, and the impact you expect.

## What to expect

This is a personal proof-of-concept project with a single maintainer, so responses are best effort:

- An acknowledgement within 7 days.
- A fix, or a decision not to fix with the reason, within 90 days of the report.
- Coordinated disclosure: the advisory is published after a fix is available, or after 90 days, whichever comes first. Reporters are credited unless they ask not to be.

## Scope

In scope: the code and the GitHub Actions workflows in this repository, on the main branch.
Out of scope: third-party dependencies (report those upstream) and forks of this repository.
